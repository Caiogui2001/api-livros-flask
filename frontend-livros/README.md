# Catálogo de Livros

Projeto desenvolvido para a atividade da faculdade, utilizando Python com Flask e React.

## Sobre o projeto

O projeto possui uma API que fornece informações de livros e uma página que mostra esses livros na tela.



## Como executar

**1. Iniciar o Flask**

Na pasta principal do projeto:

`python backend-flask/app.py`

**2. Iniciar o React**

Em outro terminal:

`cd frontend-livros`

`npm install`

`npm run dev`

Depois, acessar `http://localhost:5173/`.
